# 电商比价 · shopping-price-check

## 为什么走聚合站（别名:为什么绕直连）

京东/淘宝/拼多多官方搜索页对未登录环境全部推到登录墙或滑块风控，
未登录无法取出真实商品数据（见经验：JD→passport登录页；淘宝→结果区空转；PDD→login页）。
**凡声称不需要登录就能直连三家的 skill 均不可靠**——它们的实现底层全依赖用户 cookie 导出或第三方 MCP 服务器。

真正免登录可用的信息源是**第三方聚合比价站**，它们已抓取三家的价格和优惠数据并提供公开网页。
本 skill 以「慢慢买」为主线，其他站作为备用。

## 核心流程（慢慢买，主路径）

1. 直接构造搜索 URL（首选，最快）：
   `https://s.manmanbuy.com/m/search/result?keyword=<URL编码关键词>`
   若无效（出现"读取错误,请重试!"等解析错误），改用备用的表单提交流程（步骤 2-4）。

2. 备用表单流程：浏览器 `navigate https://m.manmanbuy.com/`

3. 定位输入框并输入关键词：
   - 用 `find_elements`（selector `input`）找普通文本框（跳过 `#__VIEWSTATE` 等隐藏域）
   - 用 `type` 填入用户要查的商品关键词（如 `iphone 15`）

4. 提交表单：用 `execute_js` 找那个**包裹了文本框的 `<form>`**并 `submit()`：
   ```js
   var forms=document.querySelectorAll('form');
   for(var f of forms){ if(f.querySelector('input') && f.querySelector('input')!==document.getElementById('__VIEWSTATE')){ f.submit(); return 'ok '+(f.action||''); } }
   return 'no form';
   ```
   正确时会导航到 `https://s.manmanbuy.com/m/search/result?keyword=...`

5. `wait_for_dom_stable`，再用 `get_text` 提取整页结果。

## 结果解析

页面会显示 `为你找到全网N条爆料好价优惠`。每条结果形如：

```
Apple 苹果 iPhone 15 粉色 128GB 套餐一
2597元
淘宝 08-04 17:00 低于双11
```

**字段**：商品名 / 价格 / 平台 + 时间 + 好价标签。

**平台标识映射**：京东自营→京东、京东商城→京东、淘宝→淘宝、天猫旗舰店→天猫、
拼多多(百亿补贴)→拼多多、唯品会→唯品会。

**好价标签**：`历史新低` 权重最高，其次 `历史最低` > `低于双11` / `30天新低` / `180天最低`。
拼多多项多为「百亿补贴」价，比价时如实标注补贴来源，不与常规价混为一谈。

输出给用户时做成紧凑对比表。要给出明确结论（哪个平台最便宜 + 是否值得买），
不要只堆链接。若条目带"淘金币+XX元"或"需88VIP消费券"等附加条件，如实标注到手价。

## 备用信息源

主路径失败时依次尝试（见 `references/sources.md`）：
- 什么值得买（smzdm）——站内搜索，爆料流
- 惠惠购物助手（huihui）——直连比价

## 边界与诚实条款

- 只能比价/查价/找优惠，**不能**替用户在三家登录下单、不能调用需登录的接口。
- 若某商品在聚合站也查不到，直接告诉用户没查到，并建议其自行在 App 内搜索。
- 不编造价格；所有数字必须来自抓取结果。
